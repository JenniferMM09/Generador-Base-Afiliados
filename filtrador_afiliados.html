Cargue el archivo

Seleccione un archivo .xlsx, .xls o .csv. Los datos se procesan en este navegador y no se envían a ningún servidor.

Si el archivo es grande, esta operación puede tardar varios minutos y requerir bastante memoria del navegador.

Elija las columnas que desea filtrar

Seleccione una o más columnas. A continuación definirá los valores permitidos para cada una, en el orden indicado.

Marque los valores que deben conservarse. La búsqueda no distingue mayúsculas, minúsculas ni acentos.

Elija las columnas del Excel final

Solo estas columnas aparecerán en el archivo descargado. El filtro se conserva aunque no incluya una columna en la salida.

Organice el orden de las columnas

Use las flechas para subir o bajar cada columna. El orden de esta lista será el orden del Excel final.
